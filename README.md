# heat-transfer
This is my simulation of heat transfer on a 10cm x 10cm x 1cm plate with different materials and initial temperatures. The goal was to be as physically accurate as possible while maintaining a decent frame rate (real time simulation).

With the scene editor you can create maps of initial temperature and materials and see them visually before running the simulation. These are also dimensionally accurate; so if you need to simulate a copper/alluminum plate that's 14.2cm by 2.8cm, you should paint a 142 by 28 pixel area before downloading it.
